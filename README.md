# 🧾 智能记账小助手

**把账单图片里的数字，整理成看得懂的收支记录。**

一个在浏览器里使用的记账小工具。可以上传账单图片识别文字，也可以手动录入、调整分类，再通过图表查看收支情况。

项目只有一个 HTML 页面，下载后就能打开。账目暂存在页面内存里，用完记得导出备份。

## ✨ 能做什么

| 功能 | 用途 |
|---|---|
| 图片识别 | 上传账单图片，提取文字，辅助录入 |
| 手动记账 | 填写日期、描述、金额与分类 |
| 分类管理 | 按餐饮、交通、购物等分类整理记录 |
| 统计图表 | 查看账目的分类分布和变化 |
| JSON 导入、导出 | 备份记录，或恢复之前导出的数据 |

## 📦 开始使用

### 1. 下载

```bash
git clone https://github.com/zcy205321334-bit/bookkeeping_assistant.git
cd bookkeeping_assistant
```

也可以从 GitHub 的 **Code → Download ZIP** 下载并解压。

### 2. 打开页面

用浏览器打开 `index.html`。

页面需要联网加载图表、数据库和识别组件。如果浏览器限制本地文件加载，可以在项目目录启动一个本地静态服务。

```bash
python -m http.server 8000 --bind 127.0.0.1
```

然后打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。

### 3. 记一笔，再导出

先手动录入一笔测试记录，看看分类和统计；也可以上传图片，核对识别结果后保存。

**当前版本把账目保存在页面内存中，刷新或关闭页面后不会自动恢复。使用结束前，请到“数据备份”导出 JSON 文件。**

## 💡 一个使用例子

```text
上传一张餐饮账单
    ↓
核对识别出的日期、金额和描述
    ↓
选择“餐饮”，保存记录
    ↓
在统计页查看分类汇总
    ↓
导出 JSON，保存这次的账目
```

下次打开页面，可以通过“数据备份 → 导入数据”恢复记录。

## 使用前知道这几件事

- **OCR 是辅助录入。** 图片清晰度、字体和排版会影响识别，保存前请核对金额与日期。
- **导入会替换当前数据。** 导入备份前，先导出当前需要保留的记录和分类。
- **目前没有账号与云端同步。** 备份文件需要你自己保存。
- 这是前端单页项目，在线依赖加载失败时，相应功能可能无法使用。
